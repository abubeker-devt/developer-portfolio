    Problems worth solving, not just assignments

    Every project here started because a real student was stuck on something. I'd rather ship a rough tool that helps ten classmates this week than a polished one that helps no one.

    GPA math shouldn't need a spreadsheet

    Students were recalculating GPA by hand every registration period. Built a calculator that handles multiple grading scales and departments, works offline, in one evening.

    Study materials get lost in group chats

    Course notes and past exams scattered across five Telegram groups. Prototyping a simple static index page that any classmate can update without touching a database.

    Small tools should run without the internet

    Connectivity on campus isn't always reliable, so everything I build for other students works fully offline — plain HTML, CSS and JS, no dependency on a server being up.
